# 大師球與神奇糖果：道具背包截圖驗收

此功能維持既有資料欄位：`masterball`（大師球）與 `rarecandy`（一般神奇糖果），不新增神奇糖果 XL 的庫存欄位，也不將 XL 合併至一般神奇糖果。

## 截圖 A：糖果與綠票同時可見

- 頂部「道具 4332/1075」，背包容量應取右側 **1075**（由既有獨立容量驗證流程確認）。
- 彩虹圓形「神奇糖果」下方標示 **x1796**，預期 `rarecandy=1796`。
- 右邊三角形「神奇糖果XL」下方標示 **x76**，不能當成一般神奇糖果，也不可得到 1872。
- 底部「特級對戰入場券」**x1**，仍須保留 `greenpass=1`。
- 畫面上的背包升級價格 **200** 不等於寶可幣持有餘額，不能填入 `coin`。

## 截圖 B：大師球與其他球同時可見

- 「大師球」在球類列表底部，紫粉色球、白色 M，標示 **x1**，預期 `masterball=1`。
- 同頁的普通精靈球 **95**、超級球 **128**、高級球 **520** 均不可拿來填大師球。
- 背包升級價格 **200** 不代表寶可幣持有餘額。

## 手動操作驗收

1. 在「AI自動掃描」中同時上傳以上兩張原圖。
2. 確認分類與擷取流程不因底部綠票忽略上方糖果。
3. 確認表單「神奇糖果」為 **1796**、「大師球」為 **1**；若能看見綠票，綠票為 **1**。
4. 對僅有神奇糖果 XL、沒有一般神奇糖果的畫面，驗證 `rarecandy` 必須留空，不應出現 76。
5. 對文字／數量模糊、只看到相鄰道具但看不到指定道具的畫面，不應猜數字；需要人工核對。
6. 最後檢查儲存與再次開啟記錄後，`st_rarecandy` 與 `st_masterball` 未被其他道具覆蓋。
